# Prompts utilizados en ChatGPT

## Prompt 1 - Generación inicial de la interfaz

Crear una interfaz web utilizando tres archivos separados: `index.html`, `style.css` y `script.js`.

La interfaz debe representar la bandera de México y permitir manipular los colores verde y rojo mediante controles.

La aplicación debe contener:
- Una sección para el color verde.
- Una sección para el color rojo.
- El nombre de cada color.
- El código hexadecimal del color.
- Controles de tono, saturación y luminosidad.
- Un espacio central para representar el escudo de la bandera.
- El nombre del alumno.
- El número de control.

Entregar el código HTML, CSS y JavaScript por separado.

---

## Prompt 2 - Ajuste del diseño

Ajustar la interfaz para que tenga una distribución similar a la interfaz proporcionada por el profesor.

La pantalla debe mostrar:
- El color verde en el lado izquierdo.
- El espacio central para el escudo.
- El color rojo en el lado derecho.
- Los controles de Tono, Saturación y Luminosidad debajo de cada color.
- El código hexadecimal debajo del nombre del color.
- Los datos del alumno en la parte inferior.

Mantener separados los archivos `index.html`, `style.css` y `script.js`.

## Prompt 3 - Funcionalidad de los colores

Agregar funcionalidad mediante JavaScript para que los controles de Tono, Saturación y Luminosidad modifiquen en tiempo real los colores verde y rojo de la interfaz.

El código hexadecimal debe actualizarse automáticamente conforme cambien los valores.

Mantener los archivos HTML, CSS y JavaScript separados.

Modificar el diseño para que se parezca lo más posible a la interfaz mostrada por el profesor.

- El nombre y número de control en la parte inferior.

Agregar un contorno negro a los bloques de color para distinguirlos visualmente.

No utilizar imágenes externas para representar la interfaz.
